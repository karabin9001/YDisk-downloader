# 🚀 YDisk Downloader (Yandex Turbo Downloader)

> **Скоростной пакетный загрузчик файлов и тяжёлых папок исходников с Яндекс.Диска и Google Drive с веб-интерфейсом, паузой и очередью файлов.**  
> Создан специально для видеомонтажёров, колористов, моушн-дизайнеров и их клиентов.

## ⚡ Главные возможности

* **☁️ Яндекс.Диск и Google Drive**: публичные папки (со всеми вложенными) и отдельные файлы обоих сервисов идут в одной очереди.
* **🚀 Прямое скачивание с CDN Яндекса**: файлы загружаются напрямую с высокоскоростных серверов Яндекс.Диска на максимальной пропускной способности вашего интернет-канала (без зависаний веб-страницы).
* **🗂️ Несколько очередей сразу**: новую ссылку можно добавить в любой момент, со своей папкой назначения. У каждой очереди своя карточка: ссылка, папка, прогресс, статус, журнал и кнопки. Очередь на паузе или в ожидании лимита не задерживает другие.
* **⏯️ Полный контроль (Play / Pause / Stop)**: ставьте любую очередь на паузу и возобновляйте её в любой момент без потери скачанных данных.
* **📁 Наглядная очередь по ссылкам и папкам**:
  * Каждая папка/ссылка отображается отдельной карточкой с индивидуальным прогресс-баром;
  * Счётчик файлов (`17 из 17`), объём (`31.5 / 31.5 GB`) и цветовые бейджи статуса (`100% Завершено`, `Скачивается`, `В очереди`);
  * Интерактивный список файлов в каждой папке.
* **🔄 Автодокачка (.part)**: если оборвётся интернет, отключится Wi-Fi, упадёт туннель или уснёт ноутбук, загрузка сама повторится с нарастающей паузой и продолжится ровно с того байта, где прервалась.
* **🛡️ Ошибки сервера не роняют очередь**: при 403, 429 и 5xx программа повторяет запрос, а если ошибка держится, откладывает файл и качает следующие. После обхода очереди она возвращается к отложенным файлам.
* **🔁 Продолжение после перезапуска**: все незавершённые очереди продолжатся сами при следующем запуске программы, каждая в свою папку. Очередь на паузе останется на паузе. Кнопка «Стоп» отменяет продолжение. Токен Яндекса не сохраняется: если очередь с токеном не докачается после перезапуска, добавьте ссылку заново с токеном.
* **🆕 Новые файлы**: когда очередь закончилась, программа перепроверяет папки и докачивает то, что в них появилось.
* **⏭️ Умный пропуск**: файлы, которые уже есть на диске нужного размера, мгновенно пропускаются и не тратят время.
* **🔑 Обход лимитов Яндекса**: встроенная поддержка авторизации через бесплатный персональный OAuth-токен (если публичный лимит исчерпан).
* **🖥️ 1-Click запуск**: приложение для macOS (`YDisk Downloader.app`, без Терминала) и Windows (`Запустить_на_Windows.bat`).

## 💻 Быстрый старт

### Вариант 1. Скачать готовым архивом (для обычных пользователей)
1. Скачайте архив проекта: нажмите зелёную кнопку **Code** ➔ **Download ZIP** (или скачайте из Releases).
2. Распакуйте архив в любую папку.

#### На macOS (MacBook / iMac):
1. Дважды кликните по приложению:  
   👉 **`YDisk Downloader.app`**
2. Через пару секунд в браузере откроется панель управления: `http://127.0.0.1:7860`. Окно Терминала не нужно — программа работает в фоне.
3. Чтобы закрыть программу, нажмите **«⏻ Выключить»** в правом верхнем углу страницы. Повторный клик по приложению просто откроет уже запущенную программу.

> **Первый запуск.** macOS может написать, что не удалось проверить разработчика. Откройте **Системные настройки → Конфиденциальность и безопасность**, внизу нажмите **«Всё равно открыть»** и подтвердите. Это нужно сделать один раз.  
> При первом запуске программа сама установит нужные компоненты (около 10 секунд, нужен интернет).  
> Держите `YDisk Downloader.app` в папке программы рядом с `app.py`. В Dock можно перетащить его ярлык.  
> Запасной вариант запуска — через Терминал: `Запустить_на_Mac.command`.

#### На Windows:
1. Дважды кликните по файлу:  
   👉 **`Запустить_на_Windows.bat`**
2. В браузере откроется веб-интерфейс программы.
> *(Требуется установленный Python 3.8+ с галочкой «Add python.exe to PATH»)*.

### Вариант 2. Запуск через Git и Терминал (для разработчиков)


## 📖 Как пользоваться программой

1. **Вставьте ссылки**  
   В поле ввода укажите одну или несколько публичных ссылок на папки или файлы (по одной на строку):
   ```text
   https://disk.yandex.ru/d/ваша_ссылка
   https://drive.google.com/drive/folders/идентификатор_папки
   https://drive.google.com/file/d/идентификатор_файла/view
   ```

2. **Выберите папку для сохранения**  
   Нажмите **«📁 Выбрать…»** — откроется стандартное окно выбора папки macOS или Windows. Путь можно и вписать вручную:
   * Для macOS: например, `/Volumes/SSD/Проект` или `~/Movies/Исходники`
   * Для Windows: например, `D:\Монтаж\Проект` или `X:\Исходники`

   По умолчанию для ссылки на папку создаётся подпапка с её именем. Галочка **«Класть файлы прямо в эту папку»** отключает это.

3. **Нажмите «⬇️ Скачать»**  
   Программа просканирует ссылки, создаст структуру папок и начнёт загрузку. Все ссылки из поля попадают в одну очередь с одной папкой. Для другой папки добавьте ещё одну очередь, это можно сделать прямо во время загрузки.

4. **Управляйте процессом**  
   Кнопки есть у каждой очереди и действуют только на неё:
   * **⏸️ Пауза**: приостанавливает поток данных и освобождает место для других очередей;
   * **▶️ Продолжить**: продолжает скачивание без потерь;
   * **🔁 Повторить отложенные**: сразу проверяет отложенные файлы, не дожидаясь времени повтора;
   * **⏹️ Стоп**: прерывает очередь, недокачанный `.part` остаётся на диске;
   * **▶️ Продолжить**: продолжает остановленную или завершённую с ошибками очередь;
   * **✕ Убрать из списка**: убирает карточку из окна, файлы на диске не трогает.

### Сколько очередей качается одновременно

По умолчанию две, значение меняется в разделе **«Дополнительно»** под формой, в поле «Сколько загрузок идёт одновременно», от 1 до 6. Каждая очередь качает файлы по одному, поэтому две очереди дают параллельную работу и не устраивают борьбу за один диск и один канал. На внешнем диске или через прокси больше трёх обычно только мешают друг другу.

Остальные очереди ждут в порядке добавления, на карточке будет статус «Ждёт своей очереди». Очередь на паузе и очередь, в которой остались только отложенные файлы, слот не занимают. Если одна и та же ссылка уже качается в ту же папку, вторая такая очередь не добавится. Если у двух разных ссылок совпал файл назначения, его качает одна очередь, а вторая дождётся и пропустит готовый файл.

## 🔑 Что делать, если Яндекс пишет «Превышен лимит скачивания»?

Когда файлы по публичной ссылке скачивает много пользователей одновременно, Яндекс включает ограничение:  
*«Превышен лимит на скачивание. Вы можете сохранить файл только на свой Яндекс.Диск»*.

### Как это обойти:
1. В интерфейсе программы раскройте **«Дополнительно»** под формой и найдите поле **«Токен Яндекса»**.
2. Перейдите по официальной ссылке авторизации Яндекса:  
   👉 [Получить токен Яндекс](https://oauth.yandex.ru/authorize?response_type=token&client_id=23cabb9da71444498308bb87ab8c0e27)
3. Нажмите **Разрешить** и скопируйте выданный код (токен).
4. Вставьте его в поле программы.  
Теперь все запросы будут идти от имени вашего аккаунта без анонимных лимитов и блокировок!

## 🌐 Google Drive

Ссылка должна быть открыта для всех, у кого она есть. Ключ API и вход в аккаунт не нужны.

**Прокси.** Если Google недоступен или работает медленно, укажите адрес прокси в поле **«Прокси для Google Drive»**, например `socks5h://127.0.0.1:1080`. Поддерживаются `socks5h`, `socks5`, `socks4`, `http` и `https`. Пустое поле означает соединение напрямую. Яндекс всегда работает напрямую.

**Дневной лимит.** Если файл скачивали слишком часто, Google временно закрывает скачивание. Программа покажет статус `⏳` в списке файлов, продолжит скачивать остальное и будет повторять попытку через 30 минут, затем реже, но не реже раза в 6 часов. Через 48 часов файл считается не скачанным.

Кнопка **«🔁 Повторить отложенные»** запускает обычное скачивание отложенных файлов вне расписания. Лимит проверяется только так: запрос первого байта (`Range: bytes=0-0`) проходит и у файла с лимитом, поэтому ничего не доказывает. Статус «лимит снят» появится, только когда файл начнёт отдавать данные. Если лимит ещё действует, в списке файлов обновится время отказа, а расписание автоматических повторов останется прежним. Программа не обходит лимит и не нарезает файл на короткие запросы.

**Документы Google.** Документы, таблицы и презентации Google нельзя скачать как обычный файл, поэтому они пропускаются. Их число показано на карточке и в итоговом статусе.
